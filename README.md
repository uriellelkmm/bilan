# Bilan trading

Un journal de trading en une seule page, en français, utilisable sur téléphone comme sur ordinateur.

## Ce que fait l'outil

- **Noter vos trades** : date, actif, achat ou vente, prix d'entrée et de sortie, quantité, frais, setup et note. Le résultat de chaque trade se calcule tout seul, ou vous le tapez directement.
- **Faire votre bilan** : résultat net, taux de réussite, gain et perte moyens, profit factor, espérance, drawdown maximum, meilleur et pire trade, séries, frais payés.
- **Voir l'évolution** : la courbe du résultat cumulé, le résultat mois par mois et par actif.
- **Filtrer** par période (ce mois, 3 mois, cette année) et par actif.
- **Sauvegarder** : export et import au format CSV.
- **Essayer avec un exemple** : des trades fictifs, sans rien enregistrer.

## Où sont gardés vos trades

- Ouvert depuis Claude : dans votre compte Claude, visibles par vous seulement.
- Ouvert ailleurs (par exemple le fichier `index.html` ouvert dans un navigateur) : dans ce navigateur, sur cet appareil. Pensez à exporter vos trades de temps en temps.

## Fichiers

- `index.html` : tout l'outil (page, style et code dans un seul fichier, sans installation).
